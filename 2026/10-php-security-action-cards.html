這次 PHP 漏洞，我該做什麼？

先看誰負責網站的 PHP 環境，再確認對應行動。

01瀏覽網站的人

一般使用者

個人裝置不用安裝 PHP 修補

修補由網站端處理。遇到網站下線，可等待公告；仍須留意異常下載、轉址與登入要求。

02委託別人代管

網站經營者

向代管商確認修補結果

詢問是否已修補這兩個漏洞，並索取公告或紀錄。只更新 WordPress、布景或外掛，不能當作 PHP 已修好。

03自己管理伺服器

系統管理者

套用 PHP 或供應商修補

依指引更新，並檢查日誌與異常存取；無法即時修補時，評估暫停對外服務或隔離系統。WAF 無法完整取代修補。

官方修補版本

8.5.128.4.278.3.368.2.35

供應商可能回補至舊版，不能只看表面版本號。PHP 7.4、8.0、8.1 本次另有最小原始碼回補，不代表恢復例行維護。使用者須向供應商確認，或依官方說明自行建置。更新也不能證明過去未遭入侵。
